# CVPR20 Submission Package

This folder contains the final paper sources, compiled PDFs, and research video.

- `main.tex`, `supplement.tex`, `numbers.tex`: LaTeX source files
- `main.pdf`: main paper
- `supplement.pdf`: supplementary material
- `CVPR20_paper_video.mp4`: final research video
- `video_README.md`: video structure and checklist audit

The source files and PDFs are also retained in `paper/`, and the video source clips
remain in `video/`.
